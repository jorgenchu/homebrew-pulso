# Pulso para Homebrew

Instala [Pulso](https://github.com/jorgenchu/pulso), el monitor del sistema para la barra de
menús de macOS, con [Homebrew](https://brew.sh).

```bash
brew install --cask jorgenchu/pulso/pulso
```

Actualizar y desinstalar:

```bash
brew upgrade --cask pulso
brew uninstall --cask pulso
```

`brew uninstall --zap --cask pulso` borra también las preferencias.
